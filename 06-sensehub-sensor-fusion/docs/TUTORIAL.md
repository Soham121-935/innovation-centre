# P06 — Conditional Verification Tutorial

1. Inspect each listed Sensor Hub and record exact board label/revision and sensor markings; do not assume BOOSTXL-SENSHUB.
2. Inspect a listed TIVA board and record full model/revision. Proceed only if it matches EK-TM4C123GXL or the documented older EK-LM4F120XL host.
3. Check the physical inventory for TivaWare, LMFlashProgrammer/other supported tools, a compatible computer, USB debug/device cables, and authorized access. Do not download, install, purchase, or borrow missing items.
4. Compare the physical BoosterPack with TI SPMU290; sensor identities and connectors are conditional until matched. Review SPMU295 setup prerequisites.
5. If any component, software, host, cable, or power information is unclear, stop without connecting/programming. Record blocker and continue to P07.
6. Only after supervisor approval and exact compatibility verification, use the manufacturer procedure to check the board stationary. Start with individual sensor channels; do not begin wireless Air Mouse/CC253x functions.
7. Preserve raw values, units, time, validity and errors. Do not claim calibrated accuracy without a reference instrument already in stock.
