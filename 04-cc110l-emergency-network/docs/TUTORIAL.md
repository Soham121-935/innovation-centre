# P04 — Conditional Tutorial

> No physical radio or legal RF profile has been verified. Do not transmit and do not treat this demo as an emergency system.

1. Read the inventory label and physical module/antenna markings. Confirm whether it is exactly TI 430BOOST-CC110L.
2. Inspect which microcontrollers/accessories are physically included. The legacy TI candidate uses an MSP430 LaunchPad; no MSP430G2 LaunchPad is listed. If no officially compatible host is in supplied inventory, record blocker and continue to P05.
3. Identify radio variant, antenna and regional profile from matching manufacturer documents. For India, obtain qualified approval before any emission; US/EU examples are not assumed legal.
4. Check only already-provided, authorized software and a safe test setup. If missing, stop; do not download/install or source tools.
5. No wiring/pin steps until exact board+host schematic matches. No RF transmission until a qualified supervisor approves frequency, power, antenna, duty cycle, and test area.
6. If every gate passes, begin with a short non-critical packet test between the two verified nodes. Record sequence, receive/ack time, loss and errors. Do not connect to machinery or safety systems.
7. Stop on interference, unintended transmission, wrong band, heating, or repeated link failure. No tests have been performed.
