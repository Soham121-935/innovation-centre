# P04 — Troubleshooting

| Issue | Check | Safe action |
|---|---|---|
| SKU/antenna unclear | Physical board/module markings vs official guide | Stop; do not transmit |
| No compatible host | Compare host model to exact BoosterPack documentation | Record blocker; no adapter/LaunchPad purchase |
| No packet reception | Host/radio identity, power, permitted profile, antenna connection and matching software | Use only official procedure; do not raise transmit power or change antenna |
| High packet loss | Link budget, interference, region-approved settings, packet timing | Record loss; stop if interference occurs; no range claim |
| Unsupported radio settings | Wrong module/region image or profile | Restore only the official verified profile; do not flash an assumed image |
| Emergency dependency proposed | Non-critical lab demo only | Reject connection to real alarms, machinery, or safety functions |

No remedies are bench-verified.
