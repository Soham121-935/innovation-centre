# P07 — Conditional Tutorial

> Do not transmit until a qualified supervisor confirms the regional RF profile. This is not a location or safety system.

1. Confirm both modules physically match BOOSTXL-CC1125 and record revision, antenna, condition, and jumper position (do not move jumper yet).
2. Check out two listed MSP430F5529 LaunchPads only after confirming exact MSP-EXP430F5529 host compatibility and that the P09/P12 sequential host allocations are respected.
3. Confirm the two-node inventory provides no multilateration; narrow expected output to link state/RSSI only.
4. Review TI SWRA520's exact wiring/power mode and the matching LaunchPad schematic. Do not apply a generic pin map.
5. Confirm existing authorized PC/USB/software access without downloading or purchasing. If absent, stop.
6. Have qualified personnel confirm local frequency/channel/power/antenna legality before any RF emission. US/EU example bands are not an India approval.
7. Only after all gates pass, run a non-critical numbered-packet test and record loss, age, RSSI, and recovery. Stop on interference or unexpected heating. No tests have run.
