# P13 — Inventory Identification Tutorial

1. Open the single listed generic sensor set only under normal lab handling; list every module/cable and record markings, quantity, and condition.
2. Match each exact part number and board revision to official manufacturer documentation. Do not guess that an item is temperature/humidity/gas/vibration.
3. Identify safe power, output type, connector, units/range, calibration, and compatible host from documents.
4. Check the actual stock for a matching controller, computer/toolchain, logger/storage, and independent reference. No such item is assumed.
5. If any gate fails, do not power/wire. Record “P13 blocked” and continue to P14; no purchase or borrowing.
6. Only after all required assets are confirmed, characterize one sensor in a safe ambient condition before anomaly thresholds are defined.
7. Freeze baseline/update policy and metrics before collecting data. No tests have run.
